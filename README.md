# PalBag — интерактивный HTML-прототип

Многостраничный демонстрационный интернет-магазин, пересобранный по исходным страницам и компонентам из переданного проекта PalBag. Это рабочий прототип на HTML, CSS и JavaScript без сборщика, серверного приложения и UI-фреймворков.

## Запуск

Из корневой папки проекта запустите любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Начальная страница — `index.html`. Рекомендуется открывать проект через HTTP для сохранения состояния в `localStorage`. Для шрифтов нужен доступ к Google Fonts; при его отсутствии подключатся системные шрифты.

## Концепция

PalBag — минималистичный бренд сумок из натуральной кожи. Визуальный язык исходного проекта сохранён: «тихая роскошь», почти монохромная палитра, редакционная типографика, крупные поля, чистая геометрия, тонкие разделители и минимум декоративных элементов. Основное внимание уделено форме изделия, материалу и деталям.

Визуальная основа взята из исходных `Main.dc.html`, `Catalog.dc.html`, `Product.dc.html`, `Header.dc.html`, `ProductCard.dc.html`, `Bag.dc.html` и мобильной главной страницы. Сохранены композиции и последовательность секций: промополоса и полноширинный hero, шесть категорий, бестселлеры, editorial-блок, новинки, statement о бренде, преимущества, подписка, социальная галерея и структура footer. В качестве визуалов используются предоставленные фотографии товаров и баннеров; если для демо-модели фотографии нет, показывается нейтральное сообщение вместо нарисованной сумки.

## Шрифты и палитра

- **Cormorant Garamond** — логотип и крупные заголовки; преимущественно Light 300, местами Regular 400. В логотипе `PAL` — Light, `BAG` — SemiBold.
- **Manrope** — основной текст, навигация, цены, формы и подписи; преимущественно 400/500.
- Основной фон — `#FFFFFF`; дополнительные блоки — `#F8F7F5`.
- Основной текст и кнопки — `#171717`; вторичный текст — `#6B6A67`; линии — `#E7E4DF`.
- Акцентные оттенки сумок: чёрный `#1C1B1A`, коньячный `#8A5A3C`, песочный `#D2C7B6`, оливковый `#6D6A58`, бордо `#5A2A2E`.
- Дополнительные состояния: успех `#3F7D58`, ошибка `#A3352B`.

Шрифты загружаются из Google Fonts в HTML-страницах. Резервные варианты: Times New Roman для антиквы, системный sans-serif для интерфейса.

## Карточки и сетка

- Изображение каждой карточки товара имеет единое соотношение **4:5**. Название ограничено двумя строками, цена и область характеристик зарезервированы по высоте, кнопка «Купить» выровнена по нижнему краю карточки; сетки сохраняют одинаковые размеры карточек в пределах каждой строки и адаптируются к ширине экрана. Категории: 4:5 на desktop и 3:4 на mobile.
- Карточка товара: бейдж сверху слева, избранное сверху справа; при наведении меняется фон/ракурс и появляются «В корзину» и «Быстрый просмотр». Под карточкой есть отдельная кнопка «Купить»: для товаров с выбором размера она ведёт на страницу товара, для остальных открывает Telegram.
- Desktop: контентный контейнер не шире 1344 px с полями 48 px; hero занимает всю ширину и 800 px высоты. Категории — 3 колонки, с вертикальным шагом у второй и пятой карточек. Секции товаров — 4 колонки.
- Каталог: фильтры слева шириной 260 px, интервал до сетки 64 px; переключатель вида меняет сетку с 3 на 4 колонки.
- Tablet: поля 32 px; шапка упрощается до бургера, центрального wordmark и иконок.
- Mobile: шапка 60 px; hero становится последовательностью «изображение 4:5 → текст и CTA», категории и товары идут по две колонки, фильтры открываются выдвижной панелью.
- Базовый шаг отступов — 8 px. Стандартные промежутки — 12, 16, 24 и 32 px.
- Радиусы скругления не используются; тени интерфейса не используются. Основные границы — 1 px.

## Страницы

Каждая страница — отдельный HTML-документ. В нём есть общий header, основной landmark `main`, footer и корневые элементы уведомлений/модальных слоёв. Страница указывает свой `data-page`; `js/app.js` строит содержимое страницы из семантических HTML-шаблонов и связывает его с интерактивностью.

- `index.html` — главная: рекламный слайдер, шесть категорий, ссылки на BALENCIAGA, CHANEL, MOSCHINO и SAINT LAURENT, бестселлеры, editorial о материале, новинки, statement о бренде, преимущества, подписка и галерея социальных сетей.
- `balenciaga.html` — отдельная брендовая категория BALENCIAGA с editorial-заставкой и автоматически собранной сеткой товаров бренда.
- `chanel.html` — отдельная брендовая категория CHANEL с editorial-заставкой и товарами из общего списка.
- `moschino.html` — отдельная брендовая категория MOSCHINO с товарами из общего списка.
- `saint-laurent.html` — отдельная брендовая категория SAINT LAURENT с товарами из общего списка.
- `catalog.html` — каталог: поиск по названию, типу, бренду и материалу; фильтры показывают только категории, бренды и цвета, для которых есть реальные товары, а также диапазон цены. Товары BALENCIAGA, CHANEL, MOSCHINO и SAINT LAURENT берутся из общего списка и доступны в соответствующих брендовых категориях.
- `product.html?id=balenciaga-le-city` — карточка товара: галерея предоставленных изображений, zoom, выбор размера и цена варианта, добавление в корзину, accordion доставки/возврата/оплаты, характеристики, отзывы и похожие товары. Идентификатор передаётся параметром `id`.
- `cart.html` — корзина, изменение количества, удаление позиции, сумма и демонстрационная форма оформления заказа.
- `favorites.html` — избранное, синхронизированное с каталогом и карточками товара.
- `about.html` — история и принципы бренда.
- `delivery.html` — доставка, оплата, возврат и обмен.
- `contacts.html` — контакты и демонстрационная форма обращения.

На страницах товара и каталога предусмотрены ссылки на связанные модели; общий header/footer доступны на всех страницах.

## Интерактивность

- Бургер-меню плавно открывается на весь экран; ссылки появляются каскадно. Меню закрывается крестиком, Escape или переходом по ссылке.
- Главный слайдер переключается каждые **4,5 секунды**; есть стрелки, индикаторы, пауза при наведении/фокусе и свайп на мобильном. При `prefers-reduced-motion` автопереключение отключается.
- Карточки ведут на `product.html?id=...`; быстрый просмотр открывает модальное окно с товаром и действием добавления в корзину.
- На карточке доступно быстрое добавление в корзину. На странице товара выбираются доступные для модели цвет и размер; варианты размера и соответствующие цены сохраняются вместе с позицией корзины и названием варианта в корзине. Для обеих версий BALENCIAGA Bel Air Carry All Bag: Small — 15 000 ₽, Medium — 18 000 ₽; для BALENCIAGA Le City: Mini — 12 000 ₽, Small — 14 000 ₽, Medium — 16 000 ₽; для всех цветовых вариантов Balenciaga Rodeo: Small — 14 000 ₽, Medium — 16 000 ₽, Large — 18 000 ₽. Chanel Maxi Flap Bag — 15 000 ₽, без неуказанных размера и цветовых опций.
- Кнопка «Купить» на странице товара открывает `https://t.me/almirkhialov`. Если у модели есть несколько размеров, пользователь сначала должен выбрать размер; до выбора ссылка заблокирована. На мобильном та же кнопка находится в фиксированной панели. Кнопки в карточках ведут на страницу выбора размера либо непосредственно в Telegram, если размера выбирать не нужно. Ссылка Telegram единая в навигационных и покупательских CTA.
- В галерее Chanel Maxi Flap Bag главное видео запускается без звука, в цикле и только при появлении в viewport; при прокрутке за его пределы воспроизведение ставится на паузу. Источник загружается через `IntersectionObserver`; при неподдерживаемом H.265, ошибке загрузки или запрете autoplay остаётся предоставленная фотография.
- Moschino Tie Me Bag стоит 13 000 ₽; товар можно добавить в корзину, цена включается в расчёт суммы.
- YSL Soft Niki Medium in Lambskin стоит 15 000 ₽; карточка товара показывает предоставленные фотографии и натуральную кожу, без неуказанных размера и цветовых опций.
- Увеличение изображения на странице товара переключается кнопкой zoom. У Chanel Maxi Flap Bag подключено внешнее видео с фото-fallback; если изображения товара не предоставлены, макетные сумки не подставляются.
- «Добавить в корзину» сохраняет позицию и подтверждает действие уведомлением; «Купить» открывает Telegram для оформления заказа, не меняя содержимое корзины.
- Количество, удаление товаров, итоги, стоимость доставки и порог бесплатной доставки в корзине работают локально.
- Оформление открывает проверяемую браузером форму; после успешной демонстрационной отправки заказ очищается. Платёжная операция и отправка данных на сервер не выполняются.
- Избранное добавляется/удаляется из карточек и страницы товара. Списки корзины и избранного хранятся в `localStorage` под ключами `palbag-cart` и `palbag-favorites`.
- Поиск доступен в шапке; мобильная иконка раскрывает поле. Результаты отображаются в каталоге.
- Фильтры и сортировка применяются к каталогу; брендовые страницы строятся из общего списка товаров по полю `brand`, без дублирования записей. Переключатель колонок работает на широком экране. На мобильном фильтры открываются отдельной выдвижной панелью.
- Форма подписки и контактов показывает локальное подтверждение, но ничего не отправляет.

## Анимации и доступность

- Hero fade: 1,2 секунды; интервал слайдов — 4,5 секунды. Подпись активного баннера появляется отдельно, тексты соседних слайдов не накладываются; на мобильном экране отображается только активный слайд.
- Открытие меню/панели: плавное появление и смещение; пункты меню появляются каскадно.
- Модальное окно: fade и небольшое смещение по вертикали.
- Секции появляются при прокрутке с лёгким смещением снизу. Для `prefers-reduced-motion` анимации сокращаются.
- Интерактивные элементы — настоящие `a`, `button`, `form`, `input`, `details`; добавлены подписи и состояния ARIA, поддержка клавиатуры и видимый focus.

## Границы прототипа

Нет серверного каталога, авторизации, API, реального платёжного провайдера, CRM, доставки, отправки e-mail или хранения заказов на сервере. Отзывы покупателей пока не собраны; блоки отзывов не содержат демонстрационных записей. Это основа для реализации магазина, а не готовая коммерческая платформа.

## Отзывы товаров

- Демонстрационные отзывы и искусственные рейтинги удалены. Пока отзывов покупателей нет, на каждой странице товара отображается нейтральное сообщение и ссылка для связи с магазином в Telegram.
- Карточки товара и главная страница не показывают отзывы, оценки или звёзды, если нет опубликованных записей покупателей.
- Для подключения настоящих отзывов понадобятся API и хранилище с модерацией. Интерфейс принимает только записи с `source: "customer"` через `window.PALBAG_REVIEWS`; записи для агрегированного рейтинга должны соответствовать опубликованным отзывам.
- Не добавляйте тексты от имени несуществующих покупателей и не используйте вымышленные оценки.

## SEO и публикация

- Подтверждённый адрес GitHub Pages хранится в `js/seo-config.js`. Там же заданы уникальные метаданные страниц и пустые настройки аналитики; не подставляйте вымышленные домены или идентификаторы.
- Для повторной генерации метатегов, `sitemap.xml` и `robots.txt` после изменения конфигурации выполните из корня проекта: `node scripts/generate-seo.mjs`.
- Статические страницы используют собственные title, description, canonical, robots и Open Graph. Карточка товара формируется JavaScript из `js/products.js`: при открытии существующего товара приложение устанавливает канонический URL с ID, уникальные метаданные, Product/Offer и цепочку навигации. Страницы корзины и избранного закрыты от индексации; неизвестный ID товара также получает `noindex`.
- Product/Offer schema использует только внесённые в каталог названия, изображения, материалы и цены. Доступность, рейтинг, отзывы и неподтверждённые сведения в структурированные данные не включаются.
- JPEG-оригиналы сохранены; для поддерживаемых фотографий рядом находятся AVIF-производные. Разметка использует `<picture>` с AVIF и исходным JPEG fallback, у изображений заданы размеры, ниже первого экрана включена отложенная загрузка. Главное изображение страницы товара и первый баннер загружаются с высоким приоритетом.
- AVIF-файлы занимают около 9,09 МБ против 11,88 МБ JPEG-оригиналов (примерно на 23,5% меньше суммарно); оригиналы не удалены.
- Sitemap формируется из индексируемых страниц и ID каталога. Для GitHub Pages проекта `robots.txt` доступен по адресу `/PalBag/robots.txt`, а не по корневому `/robots.txt` домена `github.io`; поэтому после публикации отправьте sitemap напрямую в Google Search Console и Яндекс Вебмастер и проверьте доступность их инструментами. Наличие файла внутри проекта не устраняет это ограничение платформы.
- Для Google подключите подтверждённый ресурс `https://swiftdev028.github.io/PalBag/` в Search Console и отправьте `https://swiftdev028.github.io/PalBag/sitemap.xml`. Для Яндекса добавьте тот же адрес в Вебмастер, пройдите подтверждение и отправьте карту сайта. Коды подтверждения добавляются только после получения в соответствующих кабинетах.
- После покупки домена замените `siteUrl` в `js/seo-config.js` на фактический HTTPS-адрес с завершающим `/`, затем запустите генератор повторно. Настройте домен и HTTPS в GitHub Pages, проверьте перенаправление старого адреса и повторно отправьте sitemap в обоих инструментах. Не добавляйте `CNAME`, пока домен не выбран и не настроен.
- В существующем футере указан `palbag.ru`; владение и настройка этого адреса не подтверждены. До подключения домена проверьте контактную подпись, не используйте её как canonical и не создавайте для неё DNS/CNAME без подтверждения владельца.
- GA4 и Яндекс Метрика не подключены: `googleAnalyticsId` и `yandexMetricaId` оставлены пустыми, поэтому внешние скрипты не загружаются. При добавлении валидного ID загрузчик включится автоматически; перед этим владелец должен настроить необходимое согласие и обработку данных.
- Изображения и клиентский JavaScript оптимизированы базовыми средствами; полевые LCP/CLS/INP нельзя достоверно измерить в исходниках. После публикации проверьте реальные URL в PageSpeed Insights, Search Console и Яндекс Вебмастере. Поскольку каталог и страницы товаров формируются на клиенте, проверяйте их рендеринг отдельно в инструментах обеих поисковых систем.
